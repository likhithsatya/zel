🔧 REQUIREMENTS
═══════════════════════════════════════════════════════════════════════════

System Requirements:
  • OS: Linux 20.04+, macOS 10.12+, Windows 10+
  • Disk Space: 15-25 GB free (depends on templates)
  • RAM: 2 GB minimum, 4+ GB recommended
  • CPU: 2+ cores
  • Internet: Required for builds, not for installing

Build-Specific Tools:
  • Docker (for Docker image builds)
  • QEMU (for VM image builds)
  • AWS CLI (for AWS AMI builds)
  • xorriso (for ISO builds)
  • Python3, Ansible, etc. (as needed)
